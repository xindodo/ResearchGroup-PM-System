# ResearchGroup-PM-System

项目管理系统，使用 Vue 3、TypeScript、Vite 和 Node.js，数据存储于 SQLite。

## 运行

需要 Node.js 24.14 及以上的 24.x 版本。首次安装运行 `npm --prefix apps/frontend ci`。

- 开发：`npm run dev`，访问 http://127.0.0.1:5178/ 。
- 正式本地运行：`npm run build` 后运行 `npm start`，访问 http://127.0.0.1:5180/ 。
- `/project-system.html` 兼容现有书签，与首页使用相同项目系统。
- 数据库及附件默认位于 `.local/jtgc/`。首次空库的管理员密码写入该目录 `initial-admin.txt`；已有账号和密码保持不变。
- 备份：`npm run backup`，包含数据库与附件；恢复前必须停止服务并备份现有数据。

## 功能

工作台、项目台账与概览、任务和子任务、人员分工、工时登记和人员总/周/月工时汇总、里程碑、甘特图、校内/校外单位目录、单位人员、人员资料及关联成果记录。项目仅名称必填，参与人员可多选，单位及项目来源使用目录下拉框。

系统管理员通过左下角“系统管理”维护用户、项目类型、分类、回收站及日志。项目类型改名同步关联项目，已使用类型不能删除。用户菜单提供个人资料、修改密码、刷新数据和退出登录。

账号角色为系统管理员、导师、学生、只读访客；新增和批量导入默认导师。首次启动新版时，旧专业教师、系主任、教学主任、系管理员统一归为导师，原系统管理员和只读访客保留。迁移前在数据目录 backups 中生成数据库备份并校验完整性和数据一致性，账号密码、成员类型及业务关联保留。全局管理仅限系统管理员；导师和学生按项目负责人、项目成员及任务执行人身份使用项目功能。

旧交工系系统的独立首页、栏目导航、公告、旧任务发布、相关链接和演示入口已移除。项目系统正在使用的人员资料、关联记录、账号权限、附件及审计模块继续保留。仓库清理不删除数据库、账号、历史业务记录或附件，生产服务器未在此清理中操作。

## 验证

先运行 `npm run build`，再运行 `npm test`：接口测试、工时汇总单元测试及项目浏览器测试。浏览器使用隔离临时数据库；Windows 可设置 `PLAYWRIGHT_CHANNEL=chrome` 使用本机 Chrome，CI 使用 Playwright Chromium。

组织栏目按“校内单位 / 校外单位”分类，点击单位查看人员，点击人员进入详情。单位目录统一供牵头单位和参与单位下拉框使用；现有目录默认归入校内，可编辑分类。未归属的账号人员在“未分配单位人员”中维护。人员档案可独立于登录账号创建，也可关联已有账号；移出单位保留账号。项目来源在“系统管理 → 项目来源”维护。
