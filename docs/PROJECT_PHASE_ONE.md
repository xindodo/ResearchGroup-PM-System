# 项目管理系统功能与权限

## 页面与功能

首页 `/` 与 `/project-system.html` 为同一项目管理系统。左侧提供工作台、项目、里程碑、任务、工时、组织；系统管理员左下角有系统管理入口。账号菜单提供个人资料、修改密码、刷新和退出登录。

项目仅名称必填，其余信息选填。概览包含项目简介、负责人、参与人员、牵头及参与单位、类型、来源、起止日期、状态和进度。负责人或管理员维护项目进度；参与人员可下拉多选，单位与来源使用组织目录。台账支持分类、筛选、排序、分页和 CSV 导出。

任务支持主任务/子任务、执行人、起止日期、前置关系、状态、进度及里程碑多选。执行人必须为项目成员；后台校验日期、循环依赖及并发版本。管理员与负责人分配任务，执行人员可更新自己的状态和进度。

工时逐次记录任务、成员、开始与结束时间、标签和备注；自动计算时长，支持跨日、编辑、软删除、筛选及 CSV 导出。本人可管理自己的记录，负责人和管理员可管理项目全部工时。同一人的重叠工时被拒绝。项目及全局工时按人员汇总总工时、周工时和月工时；北京时间自然周（周一至周日）与自然月，跨界记录按交集计算。

里程碑提供负责人、计划/实际日期、关联任务、前置节点、优先级、标签、说明、交付与验收、状态及进度。支持列表、看板、时间线、筛选、统计、复制和导出，后台保护依赖与完成条件。甘特图按里程碑分组展示关联任务及子任务、任务周期与进度、计划及实际日期，支持展开/收起和横向滚动。

组织顶部仅有校内单位和校外单位分类，各单位支持名称查询、新增、编辑、分类调整和受保护删除。点击单位进入人员列表，再点击人员打开资料；支持人员新增、编辑、查询、删除或移动单位。现有账号尚未归属单位时列入未分配人员。单位目录统一供项目牵头和参与单位下拉框使用，单位改名同步两类项目引用。人员支持查询、科研字段、Markdown 简介、照片和附件，以及成果、科研课题、教学和工作日常等关联历史记录。系统管理员可编辑全部人员，导师和学生只能编辑本人，只读访客不可修改。

系统管理由系统管理员使用：账号创建/编辑、角色、停用、重置密码、受保护删除、项目类型、分类、回收站和操作日志。类型改名同步已有项目并递增版本，被引用类型不可删除，至少保留一个类型。

## 数据与权限

SQLite 中 `pm_*` 表存储项目、成员、任务、工时、里程碑、目录和活动。账号、人员资料、关联记录、文件和审计为项目系统共享基础模块。管理员可管理全部项目，负责人管理本人项目，成员查看其参与项目；只读访客不可写入。写操作需登录及 CSRF 校验，更新使用版本号防止并发覆盖。

历史关联账号不能直接删除，停用保留历史。附件在本地 uploads 目录，默认不清理未关联文件，不因代码清理删除历史数据。

## 验证与运维

`npm run build` 执行类型检查和构建；`npm test` 执行接口、工时统计和项目浏览器测试，测试数据库独立。独立旧系统和静态预览测试已退役，人员、账号、上传、安全和迁移回归继续保留。

生产部署必须显式授权，所有构建在本地完成。遵守 `AGENTS.md`，结构升级先备份并验证恢复性，仅进行保留数据的迁移，禁止上传本地数据库、删除正式数据或覆盖附件。此次仓库清理未部署生产。

## 组织数据结构

新增 `pm_organizations` 和 `pm_organization_people`，版本7迁移只将既有单位名称合并入目录，默认校内分类，不改写项目、人员或附件。人员档案与账号分离，可按需关联；关联账号的人员资料仍使用同一账号档案和权限，单位归属独立版本控制。独立人员档案复用详情、科研字段、照片、附件和富文本。管理员可维护；普通账号和访客只读组织目录。单位有人或项目引用时不可删除，移出账号人员只解除单位归属。独立档案有历史关联记录时不可删除。

组织独立档案不会自动生成登录账号。项目来源维护移入系统管理。

项目新增可选“学生负责人”，从启用的学生账号中选择；项目负责人和学生负责人自动列入项目成员。学生负责人可编辑该项目、所属里程碑与任务，并在工作台中看到所负责项目。角色变为只读访客后失去编辑权限；停用账号保留历史引用。更换或清空学生负责人后，原学生的管理权限随之取消，若仍是成员则按普通成员权限使用。项目负责人名称统一为“项目负责人”，导师权限保持原样。字段保存在现有项目JSON中，旧项目默认为空，不需要数据库结构迁移或批量改写历史项目。
